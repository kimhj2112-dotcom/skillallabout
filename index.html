새로 들어온 스킬

제미나이가 모아 오고 Claude가 GitHub에서 확인한 스킬을 회차별로 모았어요.

작업 레시피

한 가지 일을 끝내려면 스킬 여러 개를 순서대로 쓰면 편해요. 단계를 누르면 그 스킬 설명이 열립니다.

설치 가이드

스킬은 SKILL.md 파일이 든 폴더예요. 어디서 쓰느냐에 따라 넣는 곳만 달라요.

① claude.ai · Claude 앱

  1. 스킬 폴더를 ZIP으로 압축 (폴더 안에 SKILL.md가 바로 있어야 해요)
  2. 설정 → 기능(Capabilities) → 스킬 → 업로드
  3. 켜 두면 관련 요청을 할 때 Claude가 알아서 불러 씁니다

Anthropic 공식 스킬(docx, pdf, pptx, xlsx 등)은 대부분 이미 들어 있어요.

② Claude Code · 플러그인 마켓

  1. 마켓 추가 → 플러그인 설치 → Claude Code 재시작
/plugin marketplace add anthropics/skills
/plugin

/plugin 메뉴에서 마켓의 플러그인을 고를 수 있어요. 저장소가 마켓을 지원하는지는 README에서 확인하세요.

③ Claude Code · 폴더 직접 복사

  1. 저장소를 git clone 하거나 ZIP으로 받기
  2. SKILL.md가 든 폴더를 아래 위치로 복사
~/.claude/skills/스킬이름/SKILL.md
%USERPROFILE%\.claude\skills\스킬이름\SKILL.md

프로젝트에서만 쓰려면 프로젝트 안 .claude/skills/ 에 넣으세요.

⚠ 설치 전에 꼭 확인

  • 커뮤니티 스킬은 남이 만든 코드예요. SKILL.md와 scripts 폴더를 한 번 열어 보고 설치하세요.
  • API 키가 필요한 스킬(ElevenLabs, Gemini 등)은 키를 .env에 두고 절대 커밋하지 마세요.
  • 설치 방법은 2026년 11월 기준이에요. 저장소 README가 항상 우선입니다.
