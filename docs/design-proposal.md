# skillallabout 사이트 디자인 시안 (제미나이, 2026-11-25)

> 제미나이 1회차 답에서 옮김. 아직 반영 안 함 — 고를 것은 현진이 정하고 Claude가 코드로 옮긴다.

## 1. 첫 화면 개선안 — 3초 안에 "내 일에 맞는 스킬"

검색어나 기술 용어를 몰라도 **지금 하려는 일**과 부족한 실무 영역(마케팅 · 대본 · 작문 · 영상 · 한국어 업무)을 바로 잇도록 위쪽을 목적 중심으로 다시 배치.

```text
+-------------------------------------------------------------------------+
| [skillallabout]   스킬 찾기   작업 레시피   설치 가이드   [신규/추천]   |
+-------------------------------------------------------------------------+
| 지금 어떤 작업을 하시나요? (3초 빠른 선택)                                |
| [📣 광고·마케팅] [🎙️ 대본·기획] [✍️ 작문] [🎬 영상] [🇰🇷 한국어업무] |
| [ 🔍 예: 유튜브 쇼츠 대본, 네이버 블로그, 랜딩 카피, 자막...   [검색] ] |
| 추천 키워드: #쇼츠훅  #SEO카피  #한국어교정  #HWP·문서  #썸네일        |
+-------------------------------------------------------------------------+
| 필터: 출처 [전체 v] | 분야 [전체 v] | 정렬 [추천순 v]    총 000개 스킬 |
+------------------------------------+------------------------------------+
| 카드 그리드                         | 상세 패널 (카드 선택 시)            |
|                                    | 1. 용도  2. 이렇게 말해 보세요(복사) |
|                                    | 3. 설치 방법(탭 전환) 4. 참고/주의   |
+------------------------------------+------------------------------------+
```

- 검색창 위에 핵심 5개 목적 칩
- 검색창 예시를 기능명 대신 실제 상황으로
- 결과가 적거나 없을 때 관련 작업 레시피로 바로 연결

## 2. 카드 · 상세 패널

- **카드에서 줄일 것** — 이름, 한 줄 설명, 분야 칩 최대 2개, 핵심 배지만. API 키 안내 · 설치 명령은 상세 패널로
- **카드 배지 추가** — `한국어 친화`(네이버 블로그 · HWP 등), `별 적음`
- **상세 패널** — 용도(어떤 상황에서) / 예시 문장 복사 / 설치 방법을 **탭**(claude.ai · Claude Code 마켓 · 폴더 복사)으로, SKILL.md 폴더 직링크 / 참고 · 주의(API 키, 유료, 별 적음, 분류 확인 필요)

## 3. 새 화면 아이디어

- **A. 3문답 스킬 추천기** — ① 필요한 결과물(글 · 대본 · 영상 · 코드 · 리서치) ② 작업 환경(claude.ai / Claude Code / 한국어 문서) ③ API 키 · 유료 괜찮은지 → 상위 3~5개 + 이어 쓸 레시피 1개
- **B. 이번 주 새로 들어온 스킬** — 수집 회차 · 날짜별 묶음, 부족 분야 필터, `별 적음` · `분류 확인 필요` 태그로 실험적/검증된 것 구분

## 4. 색 · 글꼴

지금 방향(종이색 + 주황 + Pretendard)은 유지하고 가독성 · 구분만 다듬기.

| 역할 | 색 | 이유 |
|---|---|---|
| 배경 | `#FAF7F2` | 종이 느낌 유지, 눈부심 줄임 |
| 카드 | `#FFFFFF`, 테두리 `#E7E0D5` | 카드 경계 분명히 |
| 본문 | `#1C1917` | 진한 차콜 브라운 |
| 보조 글자 | `#57534E` | 대비 확보 |
| 포인트 | `#D95D24` (호버 `#B84A17`) | 주황 유지, 버튼 대비 |
| 보조 강조 | `#1E5B4F` (배경 `#EAF4F1`) | 한국어 특화 · 레시피 배지 |

- 본문 · UI: Pretendard 유지
- 코드 · 경로 · 스킬 이름: JetBrains Mono 또는 D2Coding
